# Single-Cycle ARMv8 CPU Design

Hello! 

This repository contains a simple **Single-Cycle ARMv8 CPU** design built with Verilog HDL. The code might not be completely perfect, but it serves as a great starting point for beginners. Feel free to use this as a base and build your own code on top of it.

---

### 🛠️ Usage & Setup

Each component is written in a separate file. If you are using Vivado, simply create a new project and add all the files to your project.

⚠️ **Warning:** 
The `tb_chip_behav.wcfg` file is only useful if you are using Vivado; otherwise, you do not need to download or include it. If you are using Vivado, you can place this file directly into your created project folder.
